# Rule: Frontends in `uis/`

**Scope: file-pattern.** Active when reading or editing anything under `uis/**`.

Read [`uis/README.md`](../../uis/README.md) and the app's own README first.

## `uis/website`: public corporate site

- Stack: **Vite 7 + Tailwind CSS 4 + semantic HTML + vanilla JS**. No framework, no backend. Don't add React/Next here without confirmation.
- Routes: `/` (landing, `index.html`), `/application.html` (Brasa Points signup), `/contact.html`. The home route stays `/`.
- Forms validate in the browser (`src/validation.js`) and only show local confirmations. **Don't send or store personal data** until a `services/` endpoint exists and the developer approves the wiring.
- Copy must match the Brasaland brand in `CONTEXT.md`: 14 locations, Colombia + Florida, warm/fast/consistent. Don't claim online ordering or features that don't exist. Mark illustrative images as illustrative.
- Checks: `npm test && npm run build`.

## `uis/backoffice`: internal company app (not created yet)

- Created **only** at `uis/backoffice`, with its **own layout**, separate from the public site, and an entry view on `/`.
- Home for internal dashboards (operations, executive, procurement, HR, training). Don't create `uis/admin`, `uis/dashboard` or similar siblings.
- Shows money in **both USD and COP** (or with an explicit currency toggle), using the domain logic from `packages/brasaland-operations`, not re-implemented formulas.
- Must not import code from `uis/website` (or the reverse). Share through `packages/`.
- On creation: add `uis/backoffice/README.md`, list it in `uis/README.md` + `uis/README.es.md`, add its checks to `AGENTS.md` §2 step 3, and record the stack decision in `memory-bank/techContext.md`.

## `uis/talent-pipeline-tracker`: People & Culture tool (Milestone 3)

- **Next.js 16** has breaking changes. Read `node_modules/next/dist/docs/` before writing code. Leave its `AGENTS.md` block alone (regenerated by `next dev`).
- Never show raw API values (`in_progress`, `personal_interview`). Map them through `src/lib/labels.ts`.
- Config through `NEXT_PUBLIC_API_URL` (`.env.local`, never committed. Keep `.env.example` current).
- Checks: `npm run lint && npm run build`.

## All UIs

- Accessible, semantic markup. Every async action shows loading, success and error states.
- No secrets in client code. Only `NEXT_PUBLIC_*` / `VITE_*` variables reach the browser.
